A C implementation of SND Stream, a library to play streamed music in Pokémon Mystery Dungeon: Explorers of Sky.

This C implementation is compatible with C-of-Time (https://github.com/SkyTemple/c-of-time)

# HOW TO USE

ActorAndLevelLoader and ExtraSpace need to be applied for this version to work.

To use this in your C-of-Time repository:
- Copy the `patches`, `src` and `symbols` folder to your `C-of-Time` folder and merge with existing folders.

**OR**

- Add this repo as a submodule of your C-of-Time repo (`git submodule add https://github.com/irdkwia/snd-stream-c modules/snd-stream-c`)

Tutorial for using SND Stream: https://wiki.skytemple.org/index.php/SkySongBuilder_Tutorial.
